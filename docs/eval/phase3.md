# Phase 3 search evaluation (H2)

Generated by `npm run eval:search -w apps/api` on 2026-10-26.

- Dataset: 40 notes (`apps/api/eval/search/dataset.json`). Queries (`queries.json`): 20 use words from the target note, 20 are paraphrases written to avoid them, and 6 are off-topic (no matching note) to measure noise.
- Embeddings: `local` / `Xenova/all-MiniLM-L6-v2` (384 dims), chunks of ~200 tokens. Vector search: in-memory cosine (same ranking as Atlas). Meaning-match threshold: **0.25**.
- Indexing 40 notes took 2.0 s (including model load). Median query latency: keyword 3 ms, semantic 13 ms, hybrid 14 ms.
- recall@5 = share of queries whose expected note is in the top 5. MRR = mean of 1/rank (0 if not in the top 10).
